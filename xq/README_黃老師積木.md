# 黃老師台指期｜XQ 量化積木 V1.0 (研究草稿)
狀態：只研究與模擬，不啟動自動交易或券商帳號。

## A 當沖策略（多方及空方請分別建策略）
- 執行商品 A：近月台指期（一般 = 日盤）「連續月份指數期貨」；需確認 XQ 版本名稱。
- 關聯商品 B：執行商品本身；不要自動換成其他全日盤的標的。
- 交易商品 C：先不授權真實下單。欲比較 TX / TMF 應獨立建立績效。
- 日 K：僅取前日已完成 MA6 vs MA13；多方 MA6 > MA13，空方反之。
- 開盤氣勢：今日開盤 / 昨收 - 1 >= 0.00618（多）；<= -0.00618（空）。
- 15 分 K：09:00 第一根完成後，以 15 分 MA6/MA13 與已完成 K 判勢。
- 5 分 K：完成 K 棒收盤突破前根高點（多）或低點（空），下一根才模擬成交。
- 出場：風控停損、1 / 1.5 / 2R 三組測試；收盤前平倉。
- 盤前與開盤價資料並不保證可按該價格成交。

## B 1–3 天短波段（與 A 分開）
- 日 K 訊號：出日 K、烏雲蔽日、流星、母子 K，並以 MA6 / 13 過濾。
- 15 分 K：關鍵壓力／支撐回測後確認；5 分 K 只做細部進場。
- 出場：結構停損 / 1:1 測幅 / 最多 3 個交易日。
- 隔夜必須納入夜盤及跳空風險，不能只看日盤報酬。

## XQ 建立流程
1. 策略 > 量化積木 > 我的策略 > 新增策略。
2. 先建 A 多、A 空、B 多、B 空四組，分開保存與回測。
3. 商品池選期貨「近月（一般／日盤）」；打開支援期貨條件。
4. 先在可見欄位中尋找 MA6、MA13、跳空幅度、5/15 分鐘週期。
5. 如積木不支援 0.618% 等自訂精確參數，不能用近似選項冒充；改交由 XS 警示腳本研究。
6. 設出場、停損及持有期；只跑回測／警示，勿連接券商實單。
7. 回測口徑包含成本、滑價、轉倉、連續合約規則與樣本外檢驗。
